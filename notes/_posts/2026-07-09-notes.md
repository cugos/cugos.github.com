## 1. Zulip vs Discord vs Slack

17 responses to the survey; 15% in favor of migrating, 15% in favor of sticking with Slack, the rest with no strong opinion regarding Zulip, Discord, or other Slack alternatives; no clear winner emerged, so we recommend staying with Slack.

Motion passed unanimously to establish a private board-only Google group. There was additional conversation about which discussions are best suited for email rather than Slack; for example, Slack conversations cannot be exported. The current Google group remains open to all.

## 5. Website

The website has a lot of technical debt, with an aging codebase and deprecated features.

Stephanie is planning a website refresh. The refreshed site structure will present a slimmed-down version of the following information:

1. Community (entry/participation)
2. Events (flings): this should be preserved
3. Projects (website, BBoxFinder)
4. Governance/org details
5. Historical record

Possible options for rewriting the website include:

- Stick with Jekyll
- Eleventy: everything written in markdown
- Hugo
- Astro

Consensus is to move forward with **Eleventy** provided it can support key features like an embedded locator map. It will be the easiest for member volunteers to edit.

Historical website content will be archived.
